JudgeContext

struct JudgeContext<'a> { /* fields */ }

Carries the judge agent and its config into the measuring phase.

Fields

  • agent: &'a dyn autotune_agent::Agent
  • agent_config: autotune_agent::AgentConfig
  • make_stream: Option<Box<JudgeStreamFactory>> — Optional factory called once per judge invocation. Receives a status string and returns an event handler plus a finish closure to call after the agent returns (clears ephemeral status lines, flushes buffered text).

MeasureReport

autotune_benchmark::MeasureReport

struct MeasureReport { /* fields */ }

Result of running a single measure: the raw stdout/stderr plus the extracted metrics. Raw output is retained so callers can persist it for later inspection (e.g. by a research agent looking for context beyond the summary metrics).

Fields

  • name: String
  • stdout: String
  • stderr: String
  • metrics: autotune_adaptor::Metrics

Implements: Clone, Debug
