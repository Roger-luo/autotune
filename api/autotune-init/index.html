run_init

autotune_init::run_init

fn run_init(agent: &dyn Agent, global_config: &autotune_config::global::GlobalConfig, repo_root: &std::path::Path, user_input: &dyn UserInput, config_validator: Option<&ConfigValidator<'_>>) -> Result<InitResult, InitError>

Run the agent-assisted init conversation.

user_input handles all user interaction (text prompts, option selection, approval). Use TerminalInput for real CLI sessions or MockInput for testing.

If config_validator is provided, it is called after user approval to validate the config (e.g., by running a trial measure). On failure, the user is asked whether to let the agent revise the config.

ConfigValidator

autotune_init::ConfigValidator

type ConfigValidator<'a> = dyn Fn(&autotune_config::AutotuneConfig) -> Result<std::collections::HashMap<String, f64>, String> + 'a;

Callback to validate a proposed config before finalizing.

Called after the user approves the assembled config. Typically runs the measure commands and tries metric extraction. Returns extracted metrics on success, or a detailed error string (including measure output) on failure.
