Stream

autotune::stream_ui::Stream

struct Stream { /* fields */ }

A streaming UI session that forwards agent events to stderr with buffered markdown rendering.

Create one per agent invocation. Call handler() to get an EventHandler (you can call it multiple times; all handlers share the same state), pass it to the agent, then call finish() after the agent returns to flush any trailing buffered markdown and clear the ephemeral status line.

All fields are private.

Methods

fn research(status: &str) -> Self

Stream for the research agent. Buffers markdown and suppresses the <plan> / <request-tool> XML payload once it begins.

fn implementation(status: &str) -> Self

Stream for the implementation agent. Buffers markdown; there is no protocol payload to suppress.

fn judge(status: &str) -> Self

Stream for the judge agent. Buffers markdown; no protocol payload to suppress.

fn handler(&self) -> EventHandler

Build an EventHandler for the underlying agent. Safe to call multiple times — each returned handler shares the same buffering state.

fn finish(&self)

Flush any buffered markdown, render a final newline, and clear the ephemeral status line. Call after the agent returns.

TerminalToolApprover

autotune::stream_ui::TerminalToolApprover

struct TerminalToolApprover { /* fields */ }

Interactive approval for runtime tool requests from the research agent.

Each request shows the tool + scope + reason and asks the user to allow (for the rest of the task run) or deny. Hard-denied tools are rejected upstream before reaching this type.
